# Правила для агентов в этом репозитории
1. Начало сессии: прочесть JOURNAL.md (протокол возврата) и SPEC_FINAL.md. Больше ничего.
2. Мораторий (З-0010): новые архитектурные документы запрещены до гейта E1.
   Разрешены: код, тесты, отчёты экспериментов, записи в JOURNAL.md.
3. Два правила ревью: (а) нет ветвлений по типу экземпляра в core/;
   (б) нет семантики в body/. Нарушение = отклонить.
4. Нидана-CI обязателен: события ядра несут метку Nidana; ассерты порядка в тестах.
5. Конец сессии: обновить «Текущее состояние» и «Следующее действие» в JOURNAL.md,
   добавить запись З-NNNN о принятых решениях. Сессия без записи = сессии не было.
6. Архив (docs/archive) читается только по прямой ссылке из журнала.
7. Продукт-слой (MANIFESTO.md, docs/VISION.md, docs/ROADMAP.md,
   docs/GOALS_AND_ACCEPTANCE.md, docs/ARCHITECTURE_DECISIONS.md,
   docs/TRADEOFFS_ITERATION_1.md, docs/HYPOTHESES.md) — витрина для
   владельца: читается по запросу, НЕ при старте сессии; обновляется
   только вслед за записью З-NNNN в журнале. Несущая истина — журнал
   и SPEC_FINAL; при расхождении продукт-слой чинится, не наоборот.
