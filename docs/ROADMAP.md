# ДОРОЖНАЯ КАРТА ПО СПРИНТАМ

### Статус: продукт-слой (З-0021). Календарная проекция лестницы E1–E7 (SPEC §6).
### Ритм: работа Claude измеряется часами, рефлексия владельца — днями.

---

## Правила ритма

1. **Спринт = пакет работы Claude (часы) + точка рефлексии владельца (день).**
2. Claude НЕ ждёт владельца, если следующий шаг не требует его решения;
   go/no-go гейты (E1, E2, …) требуют владельца всегда.
3. Каждый спринт закрывается тремя артефактами: отчёт в experiments/reports/,
   запись З-NNNN в журнале, обновление docs/HYPOTHESES.md.
4. Провал гейта — это результат спринта, а не его срыв: гейты спроектированы
   как самый дешёвый способ узнать правду.

## Карта

```
S0 Портфель ──► S1 Аудит-конвергенция ──► S2 Дыры ──► S3 [E1] ──► S4 [E2 ★] ──► S5 [E3+E4] ──► S6 Класс v1.0
   готов          ЗАКРЫТ (З-0024)           ИДЁТ         гейт      ГЛАВНАЯ СТАВКА    гейты        пилот
```

### S4 «Гейт E2 — ГЛАВНАЯ СТАВКА ★» — Claude ≈ 24–40 ч · владелец ≈ 2–3 дня
Сборка: 10–100 настоящих независимых сантан (З-0009) на пересекающихся

Этапы: (а) генерация шардов + разметка; (б) прогон популяции; (в) измерение

Параллельно — батарея Экзаменатора на О-3 (binding); при провале
эмерджентности границ — включается план Б (временный токенизатор) и E2
перепрогоняется.
**Пройден** → рой над общей гетерархией ВОЗМОЖЕН; открывается всё остальное.
**Провал** → стоп программы; итерация SigRef/handshake; повтор S4.
Это и есть точка «прорыв или нет» всего портфеля.
