# VISION — концептуальное видение FirstAGI

### Статус: продукт-слой, консолидация (З-0021). Несущие решения — в JOURNAL.md и SPEC_FINAL.md.

---

## 0. Полярная звезда (З-0040)

**≤ 10 млн параметров (строгий счёт) рассуждают на уровне моделей 200B+.**
Уровень L1 — рассуждение без знаний (ARC-AGI-1/2 + свежие процедурные
задачи), L2 — языковые рассуждения. Паритет = счёт не ниже эталона ≥ 200B на
том же стенде. Статус — M0. Подробно: `NORTH_STAR.md`.

Как это соотносится с разделом 1: роевой интеллект над Алаей — путь, а
Полярная звезда — мера, по которой путь проверяется извне. Почему 10М может
хватить: большие модели тратят параметры в основном на хранимое знание, а
рассуждению о новой структуре его нужно мало; рассуждение у нас — топология
гетерархии, выросшая из разрешённых конфликтов, а не объём матриц.

## 1. Где прорыв (вердикт куратора портфеля)

Гипотеза владельца: прорыв — **роевой интеллект агентов над общей
гетерархией обобщений человеческого опыта**; как в алая-виджняне, существа
рождаются в ней, путешествуют по ней и обогащают её содержание.

Вердикт: гипотеза принимается как «полярная звезда», но прорыв как
портфельная ставка формулируется точнее. У проекта два актива разного рода:

**Актив А (уже реальный): выращиваемое ядро с нетривиальной эмерджентикой.**
Стенд (~30 компонентов, 1358 тестов, 26 гипотез) дал три результата,
которых нет ни у кого:
- ёмкость рабочей памяти 7±2 **выведена системой из опыта**, а не задана
  константой (H22) — сильнейший внутренний тест самосогласованности;
- парадокс умного учителя (H7): подача сложного первым разрушает обучение
  (−52.7%) — куррикулумная экономика получила закон;
- продуктивное сновидение = реплей непонятого после смены домена (H25/H26),
  давший кросс-доменную мета-генерализацию (chain = 30).

**Актив Б (ставка): Алая — общая гетерархия, в которой живут существа.**
Это и есть роевой интеллект владельца. Но между А и Б стоит один
фальсифицируемый мост — **тождество смыслов (гейт E2)**: способны ли
независимо выращенные сантаны порождать смыслы, которые Алая опознаёт
как один и тот же смысл (общий базис L0 + HDC-адреса + трёхрежимный
автомат строитель/верификатор/арбитр). Если мост стоит — рой, башня,
переселение и «Класс» становятся инженерией. Если нет — миллион агентов
это миллион генераторов шума.

**Следовательно: прорыв = A + мост E2. Всё внимание и все ресурсы — туда.**
Не башня, не масштаб, не Rust, не мультимодальность. Одна ставка,
один kill-gate, самый дешёвый способ узнать правду.

## 2. Форма системы — одним взглядом

```
                    ┌─────────────────────────────┐
                    │  АЛАЯ (то же ядро)          │  хранилище человечества:
                    │  драйверы: SantanaDriver×F  │  гетерархия семян-смыслов,
                    │  Ядро-10М = гравитационный  │  Ядро-10М ≈ 40 GB RAM
                    │  фон ∩ порог karma_density  │
                    └────────▲──────────┬─────────┘
                    uplink   │          │  downlink (только канал Педагога:
        (COMMIT-обобщения:   │          │  PROBE / FEED / SEED / RETIRE)
        f_cur, f_tgt, cmd)   │          ▼
                 ┌───────────┴─────────────────────┐
                 │  САНТАНЫ (то же ядро)            │  смертны, дёшевы, массовы;
                 │  драйверы: CharDriver (сказки)   │  слепы к рою: Алаю не
                 │  или HumanTeacherDriver (Класс)  │  отличают от учителя
                 └──────────────────────────────────┘
```

- **Один бинарник.** Различие агентов — только конфигурация драйверов.
- **Гетерархия, не дерево.** Внимание — коллапс в точке максимального
  противоречия; бюджет конкурентов W = 7±2 у всех, всегда.
- **Рождение существа** = SPAWN(Ядро ∪ персональный overlay).
  **Путешествие** = собственный поток внимания по общей гетерархии.
  **Обогащение** = uplink закоммиченных различений (и вопросов!).
- **Смерть и переселение** = RETIRE → дистилляция кармы → новое рождение
  с поведенческим гейтом непрерывности (знания И зоны вопросов).

## 3. Почему это антитезис LLM, а не конкурент по их правилам

| LLM-парадигма | FirstAGI |
|---|---|
| Триллионы параметров в матрицах | 10⁷ различений с явной статистикой |
| Тренируется на со-встречаемости | Выращивается траекториями внимания |
| Reward / loss | Снятие структурной неопределённости |
| Знание неадресуемо | Каждый дефицит имеет адрес (узел) |
| Не умеет спрашивать по-настоящему | Подлинный вопрос — критерий живости |
| Масштаб = больше параметров | Масштаб = глубина башни при W=7±2 |
| 200B+ параметров ради рассуждений | Цель: те же рассуждения при ≤ 10M (NORTH_STAR) |

LLM в проекте есть — но на штатных местах: оракул в Teacher Queue и
Педагог Алаи. Внешний LLM нельзя переселить (нет траекторий внимания) —
переселяется его ученик: сантана, выращенная на его ответах.

## 4. Продуктовая линия

**v1.0 «Класс» (= реинкарнационная песочница, З-0011).**
10–30 пар «ученик — персональная сантана». Ученик отвечает на подлинные
вопросы своей сантаны и вживую видит, как его ответы выращивают разум
(GUI графа). Неотвеченные вопросы сантаны = карта пробелов самого ученика
= его персональный куррикулум. Алая класса = карта фронтира группы для
учителя. Психологические интерпретации человека запрещены шаблоном отчёта.

**Пост-v1.0 (заморожено до E2/v1.0):** башня агрегаторов (E6), эпохи
алфавита (E5), NurseryDriver, открытая сеть, мультимодальные драйверы.

## 5. Числовая рамка (для калибровки амбиции)

- 10⁷ смыслов ≈ 8⁸ — квинтэссенция человечества ≈ ёмкость одного зрелого ума.
- Бюджет Полярной звезды — 10⁷ **параметров** при строгом счёте. Оценка
  Ядра-10М в ~40 GB (≈ 10¹⁰ чисел) превышает его на три порядка — открытый
  вопрос О-8; измерение — вызов C-12.
- Закон фан-ина F = W/(1−β): при β ∈ [0.98, 0.997] один агрегатор держит
  350–2300 подопечных — эмпирика 7³–7⁴ выведена из двух констант.
- Класс v1.0 (10–30 пар) заведомо внутри F одной Алаи — башня не нужна.
