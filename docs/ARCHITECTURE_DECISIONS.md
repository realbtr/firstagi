## Решения ретро З-0047: принят контракт, реализация по гейтам

| № | Решение | Альтернатива / проверка | Статус реализации |
|---|---|---|---|
| A-30 | Постоянный цикл выбора действия, проверки или ожидания — ближайшая цель | fixed/FIFO/random + frozen model при том же task/budget; H35, AC0/AC1 | компоненты есть; сквозной опыт не пройден |
| A-31 | Фактический исход отдельно от поддержки Gen; unknown ≠ negative | прерывание/недоступность против наблюдённого расхождения; H27/H30 | целевой контракт; event adapter нужен |
| A-32 | Локальные кандидаты W отдельно от опубликованных неизменяемых B | повтор одного источника, replay, отрицательные/граничные случаи; H30/H33 | provisional есть; causal revisions отсутствуют |
| A-33 | Локальность — счётчики и гипотеза, не константа 7±2 | наращивать нерелевантную базу, records visited/step + task quality; H29 | в текущем ядре есть глобальные сканы |
| A-34 | Свой checkpoint, публикация и топология наследнику — разные операции | B0/B1, минус-дельта, replay без эпизодов у наследника; H31 | own pickle есть, наследование не доказано |
| A-35 | AC0→AC1→AC2 раньше роя; E2 ограничивает свою ветку | отрицательный E2 не останавливает одиночное обучение | принято изменение порядка работ |
| A-36 | Кодировщик/вопросник/LLM — явный scaffold с ablation | удаление/ослабление при фиксированной среде; H32 | текущие удобные модули сохранены и маркируются по опыту |
| A-37 | Совместимость новых baseline с текущим Python-стендом через тонкие адаптеры | без greenfield, без отдельного reasoner на канал; H27/H35 | ближайшая реализация — AC0 |
