## ПОДГОТОВЛЕННЫЕ К ПРОВЕРКЕ (гипотезы гейтов)

**HE1 · Токен-агностичность реальна.** Ядро работает поверх «перцепции
знаний» (SantanaToken) без изменения кода. Проверка: гейт E1 (S3).
Фальсификация: Алая не строит граф без ветвлений по типу экземпляра.

**HE2 ★ ГЛАВНАЯ · Тождество смыслов.** Независимо выращенные сантаны
порождают смыслы, отождествимые трёхрежимным автоматом на общем базисе
L0 + HDC-адресах: precision/recall ≥ 0.9/0.8 послойно. Проверка: гейт E2
(S4). Фальсификация = стоп программы. Это ставка «рой над общей
гетерархией возможен».

**HB · Границы слов эмерджентны на char-драйвере (О-3).** Проверка:
батарея Экзаменатора в S4. Фальсификация не убивает программу: план Б —
временный токенизатор (К-4). Родственна открытому вопросу стенда
«что обозначает Gen символьного драйвера».

**HE3 · Карантин по разнообразию тегов держит эхо.** Слепые переоткрытия
коммитятся, инъецированное эхо — нет. Проверка: гейт E3 (S5).

**HE4 · Downlink не убивает Почемучку.** Доля genuine-вопросов новичка
>80% при работающем downlink; >50% вопросов закрыто без LLM. Проверка:
гейт E4 (S5). Центральный тест на догматизацию.
