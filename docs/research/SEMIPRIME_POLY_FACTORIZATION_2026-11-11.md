# Полупростое как произведение двух квадратичных многочленов: переносы разрядов и частота удачного основания

**Короткий ответ.** Представление полупростого `N = p·q` в виде
`N = (a x² + b x + c)(d x² + e x + f)` при разумном выборе основания `x ≈ N^{1/4}`
со стороны решателя сводится к *факторизации квартики над ℤ* — а это полиномиально
по числу знаков. Поэтому стоимость метода целиком определяется тем, **сколько
оснований `x` приходится перебрать, прежде чем «цифровой» многочлен распадётся**.
Переполнение разрядов (переносы) при перемножении — не техническая помеха, а
*суть препятствия*: для случайного сбалансированного `N` младший коэффициент
`cf = (p mod x)(q mod x)` почти всегда ≥ `x`, и удачного основания в рабочем окне,
как правило, попросту нет. «Легко» основание подбирается лишь когда оба множителя
имеют малые младшие разряды в общем основании — то есть для чисел **специального
вида** `N ≈ (x₀²+малое)(x₀²+малое)`; там `x ≈ N^{1/4}` срабатывает мгновенно
(проверено до 128 бит). Для случайных полупростых метод не даёт выигрыша перед
обычной факторизацией.

## 1. Постановка и тождество

Перемножение двух квадратных трёхчленов:

```
(a x² + b x + c)(d x² + e x + f)
    = ad·x⁴ + (ae+bd)·x³ + (af+be+cd)·x² + (bf+ce)·x + cf.
```

Идея метода со стороны решателя, знающего только `N`:

1. выбрать основание `x`;
2. записать `N` в системе счисления по основанию `x`: `N = Σ Dᵢ·xⁱ`, цифры `Dᵢ ∈ [0,x)`;
3. образовать «цифровой» многочлен `P_x(t) = Σ Dᵢ·tⁱ` (это ровно тот же `N` при `t=x`);
4. разложить `P_x(t)` над ℤ. Если есть множитель `g` степени ≥ 1 с `1 < gcd(g(x), N) < N`,
   то `g(x)` — делитель `N`. Так как `N` полупросто, это в точности `p` или `q`.

**Почему это вообще может быть дёшево.** Шаг 4 — факторизация многочлена над ℤ —
*полиномиален* по степени и числу знаков (резольвента кубики для квартики; в общем
случае LLL/Цассенхаус). Экспоненциальной «дороговизны факторизации целых» здесь
нет. Вся трудность переехала в один вопрос: **при каком `x` многочлен `P_x` вообще
распадётся нетривиально?**

## 2. Связь коэффициентов с разрядами `p` и `q`

Пусть `x` выбрано так, что и `p`, и `q` — трёхзначные в основании `x`, то есть
`x² ≤ p, q < x³`. Для сбалансированного `N` (где `p ≈ q ≈ √N`) это окно
`x ∈ (N^{1/6}, N^{1/4}]`. Тогда `p = a x²+b x+c`, `q = d x²+e x+f` — это просто
разряды `p` и `q` по основанию `x` (`a,b,c,d,e,f ∈ [0,x)`), а коэффициенты из §1 —
**свёртка** этих разрядов:

```
s₄ = ad,  s₃ = ae+bd,  s₂ = af+be+cd,  s₁ = bf+ce,  s₀ = cf.
```

Истинные разряды `N` совпадут со свёрткой — `Dᵢ = sᵢ` — **тогда и только тогда,
когда нет переносов**, то есть все `sᵢ < x`. Это и есть «избежать переполнения
разрядов»: при `sᵢ < x` цифровой многочлен `P_x` буквально равен `p(t)·q(t)` и
распад тривиален.

## 3. Где возникает переполнение и что им управляет

Выбор `x ≈ N^{1/4}` делает `x² ≈ √N ≈ p ≈ q`, поэтому старшие разряды малы:
`a = ⌊p/x²⌋ ∈ {1,2,3}`, аналогично `d`. Значит `s₄ = ad` почти всегда < `x` — **это
единственное, чем решатель реально управляет** (выбором `x` около `N^{1/4}`), и это
же делает старший коэффициент квартики маленьким, с немногими делителями — то есть
условие `ad = s₄` легко разложимо.

Остальные коэффициенты — произведения разрядов *полного* размера (`b,c,e,f` порядка
`x`), поэтому `s₀=cf`, `s₁`, `s₂` достигают ~`x²` и **переполняются почти всегда**.
Ключевой — младший разряд:

```
s₀ = cf = (p mod x)·(q mod x).
```

Младшая цифра `N` жёстко равна `D₀ = (p mod x)(q mod x) mod x`. Чтобы распад давал
правильные множители без «заёмов» в константном члене, практически необходимо

> **условие-воротца:  (p mod x)·(q mod x) < x.**

Переносы в *средних* коэффициентах факторизация квартики иногда «вытягивает» через
отрицательные коэффициенты множителей (пример ниже), но младший член простит
гораздо реже. Ни увеличение `x` (меньше основание → больше разрядов → *больше*
перекрёстных произведений), ни уменьшение (`x ≈ √N`, множители линейны → всё
сваливается в один член `be`) переполнение не убирают. **Для произвольного `N`
основания, снимающего переполнение, выбрать нельзя — не зная `p,q`.**

### Переносы бывают, а распад всё равно находится

Реальный случай из замера: `N = 140 549 861 = 15053 · 9337`, основание `x = 87`.

```
p=15053 = [1, 86,  2]₈₇      q=9337 = [1, 20, 28]₈₇
свёртка p·q = [cf, …] = [56, 106, 1750, 2448, 56]  → есть коэффициент ≥ 87 (перенос!)
истинные разряды N в базе 87:  2·t⁴ + 39·t³ + 38·t² + 12·t + 56
распад над ℤ:  (t² + 20 t + 28)·(2 t² − t + 2)
   t=87:  9337 · 15053 = N     ✓  (младший член cf = 2·28 = 56 < 87 — воротца пройдены)
```

Перенос в `s₃=106` поглощён отрицательным коэффициентом `−t`; но «воротца»
`cf < x` выполнены — поэтому распад и существует. Это показывает, что
факторизация квартики **строго сильнее** наивного критерия «без переносов».

## 4. Как часто `x` подбирается легко

### Вероятностная оценка (прогноз)

`p mod x` и `q mod x` при переборе `x` ведут себя как равномерные на `[0,x)`.
Для `U,V ~ Unif[0,x)`:

```
P[ U·V < x ] = (1 + ln x) / x.
```

То есть на *одно случайное основание* «воротца» срабатывают с вероятностью
`≈ (ln x)/x` — исчезающе малой. В окне `x ∈ (N^{1/6}, N^{1/4}]` около `N^{1/4}`
оснований, значит ожидаемое число оснований, прошедших воротца,
`~ N^{1/4} · (1+ln x)/x ≈ 1 + ¼·ln N` — порядка `log N`. Но это лишь *кандидаты*:
средние коэффициенты должны ещё сойтись, чтобы квартика действительно распалась,
что срезает счёт дополнительно. Итог прогноза: **рабочих оснований у случайного
`N` в среднем меньше одного, и доля падает с ростом `N`.**

### Измерение (результат)

`A.` «Чистое» основание (все `sᵢ < x`), случайные сбалансированные полупростые,
40 чисел на разряд:

| биты `N` | окно `x ≤ N^{1/4}` | есть хоть одно основание | среднее число/`N` |
|---:|---:|---:|---:|
| 24 | 55  | 6/40 | 0.15 |
| 28 | 110 | 1/40 | 0.03 |
| 32 | 217 | 4/40 | 0.12 |
| 36 | 461 | 1/40 | 0.03 |
| 40 | 928 | 0/40 | 0.00 |

`B.` Со стороны решателя (реальный распад квартики, допускает «заёмы»), доля
оснований окна, дающих факторизацию, 25 чисел на разряд:

| биты `N` | размер окна | доля удачных оснований | успех хотя бы при одном `x` |
|---:|---:|---:|---:|
| 20 | 18  | 0.0087 | 3/25 |
| 24 | 40  | 0.0010 | 1/25 |
| 28 | 89  | 0.0031 | 5/25 |
| 32 | 186 | 0.0004 | 2/25 |
| 36 | 371 | 0.0001 | 1/25 |

Обе таблицы согласуются с прогнозом: удачное основание — редкость, и частота
убывает с размером. Даже когда оно есть, чтобы его найти, надо просканировать
~`N^{1/4}` оснований.

### Противоположный регим: числа специального вида

Пусть `p = x₀² + c`, `q = x₀² + f` с малыми `c,f` (хвосты `≪ x₀`). Тогда при `x = x₀`:
`b=e=0`, свёртка `(ad, 0, c+f, 0, cf)` — вся без переносов, и
`P_x(t) = t⁴ + (c+f)t² + cf = (t²+c)(t²+f)`. Решатель берёт `x ≈ N^{1/4}` и
попадает сразу:

| биты `N` | `x₀` | `c, f` | где сработал решатель |
|---:|---:|---:|:--|
| 40  | 649 | 6, 40 | `x = round(N^{1/4}) − 1` |
| 64  | 36903 | 2, 14 | `x = round(N^{1/4}) − 1` |
| 96  | 12667956 | 1, 31 | `x = round(N^{1/4}) − 1` |
| 128 | 2653940617 | 12, 58 | `x = round(N^{1/4}) − 1` |

Это в точности числа, оба множителя которых чуть больше общего квадрата `x₀²` —
алгебраически особый случай (родня факторизации Ферма и специального решета
числового поля, SNFS). Обобщённо: **`x` подбирается легко ⇔ `p` и `q` имеют
малые младшие разряды в общем основании.**

## 5. Сложность и вывод

- **На одно основание:** перевод в систему счисления + факторизация квартики над ℤ —
  `poly(log N)`. Условия на коэффициенты действительно «легко разложимы»: `s₄ = ad`
  мало (мало делителей) при `x ≈ N^{1/4}`; `s₀ = cf` фиксирует делители младшей цифры;
  квартика решается резольвентой кубики.
- **Число оснований для гарантии:** ~`N^{1/4}`. Итог ~`N^{1/4}·poly(log N)` —
  *экспонента по длине входа* `log N`. Это уровень Полларда-ρ / Ферма и несопоставимо
  хуже ECM (`L_p(1/2)`) и NFS (`L_N(1/3)`).

**Ответ на вопрос.** Для *случайного* сбалансированного полупростого удачное
основание `x` в рабочем окне фактически отсутствует уже начиная с ~30–40 бит, а
поиск его сканированием стоит ~`N^{1/4}` — метод не даёт выигрыша. «Легко» и сразу
(`x ≈ N^{1/4}`, без перебора) основание находится лишь для чисел специального вида,
где оба множителя близки к общему квадрату с малыми хвостами. Практическая
ценность конструкции — концептуальная (сведение факторизации целого к факторизации
многочлена) и для `N` особой алгебраической формы, а не как общий алгоритм.
