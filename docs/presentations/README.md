## Правила

1. Артефакты каждого выпуска — в подпапке `P<N>_<дата>_<тема>/`.
2. Формат P1–P3: короткая колода (10–15 слайдов) + одностраничный
   конспект в md; P2 и P3 дополнительно — статья на Хабр.
3. Материал берётся из журнала, отчётов experiments/reports/ и
   docs/HYPOTHESES.md — презентация не вводит новых утверждений
   (мораторий З-0010 распространяется и на слайды).
4. Черновики готовит Claude в конце соответствующего спринта;
   финализация и подача — владелец (его «дни рефлексии»).
