## Что не сработало

2. **Документ заменяет опыт.** Три дня без строки в `core/`. Каждая следующая

3. **Записи ожидания.** З-0080 фиксирует только ожидание условия; полезное
   (разрешение владельца) уместилось бы в одну строку PR.

## Находка ретро: правило допуска N3 выключает и seen

v2 даёт ровно **два** предъявления каждой открытой пары. N3 требует p ≥ 2, где p
— число исполнений, в которых *замороженный прогноз* Gen совпал с исходом. На
первом исполнении Gen ещё не существует — оно его порождает, прогноза нет.
Значит, после training p ≤ 1 у любого Gen, допуска нет, native abstain везде:
**seen ≈ 0, closed ≈ 0**. Development не проверил бы ничего, кроме этого.

## Решения

**R1 · Прогноз по построению — обязательный раздел.** Любой протокол, дизайн и
implementation PR содержит таблицу «класс задач/arm → ожидаемый исход при
буквальной реализации» с выводом из текста, до ревью. Ревьюер проверяет её, а не
выводит заново.

**R2 · Код вместо новых спецификаций.** Для A1–A3 новых design-документов нет:
всё нужное — в PR (описание + тесты §7) и записи журнала ≤ 15 строк. Новый
документ допустим только по стоп-правилу N5.

**R3 · Ожидание не пишется в журнал.** Если пакет только ждёт условия, он не
создаёт записи З-NNNN; разрешения владельца — строкой в PR/HANDOFF.

**R4 · Принять N3 с двумя поправками** (условие владельца для слияния PR #27
этим выполняется после их внесения; повторного ревью не нужно):
- **N3a.** p считает различные observed actual receipt, согласующиеся со связью
  Gen, **включая порождающий**; n — противоречащие. Допуск p ≥ 2 и p/(p+n) > 0.5
  остаётся и совпадает с witness v2 («два различных receipt»). Тест: после ровно
  двух проходов связь seen-пары допущена; после одного — нет.
- **N3b.** В ambiguous-проверку и конкуренцию команды входят только Gen со
  связью именно с этой командой. Gen без `oper_id` (обычные token-цепи) команду
  не делают ambiguous. Тест: token-цепь, предсказывающая иной следующий признак,
  не блокирует команду.

Прогноз по R1 после N3a/N3b: seen → до 1.00 при исправной части A, closed ≈ 0.
