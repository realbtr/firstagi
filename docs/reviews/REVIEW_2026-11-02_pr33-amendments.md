## Поправки

**W1 · Правило допуска одно для всех Gen — действует N3a.** В V3 я написал
«p≥2 замороженных прогноза». Это расходилось с принятым N3a
(NATIVE_OPERATION_CHOICE_v0_1.md §3.4): p считает различные observed actual
**включая порождающее**, то есть допуск требует origin и одного
положительного замороженного прогноза. Ошибка ревьюера. Codex заметил
расхождение и правильно вынес его на решение, а не изменил молча.

Отдельное требование `pf≥2` только для connecting Gen означало бы два правила
допуска по типу носителя. Это нарушает правило 3 («один алгоритм») и меняет
теорию поддержки, то есть тот самый случай N5. Поэтому:
- Для connecting Gen действует N3a без изменений: p ≥ 2 включая origin,
  p/(p+n) > 0.5. Счётчики origin и forecast в manifest по-прежнему различаются
  явно (это полезно для аудита).
- Если владелец захочет строже, это новая версия правила для **всех** Gen,
  с ревью и до данных, а не исключение для части B.
- Пересчитать V3. Однородный блок: actual 1–2 создают K0, actual 3 расширяет
  K до K1 (origin), actual 4 даёт первый прогноз и допуск — **4 actual на O**.
  Неоднородный блок с двумя местностями — **8 actual на O**. Нижняя граница
  бюджета протокола соответственно 4m и 8m. Запрет ослаблять правило остаётся.

**W2 · Какое событие пары — origin.** В расчёте origin — первое событие пары.
Это расходится с расширением, где origin — новое, вызвавшее создание событие.
Должно быть единообразно: origin — событие, которое **вызвало** создание
носителя (второе событие пары), а более раннее тратится на построение K.
Счёт от этого не меняется, но меняется аудит: прогноз носителя не может
относиться к событию раньше его origin.

**W3 · Ключ полной таблицы объявить явно.** Опора x — тоже публичный
признак. Если полная таблица включает x, на новых опорах она не переносит
ничего, и это ожидаемый исход по построению, а не находка. В протоколе AC0-T
указать точный ключ каждой табличной arm. Желательна промежуточная arm
«таблица по (t, n)»: prior «x не влияет» дан ей явно, тогда как K должен
вывести его сам. Так видно, что именно добавляет обобщение условий.
