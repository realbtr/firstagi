# ЦЕЛИ И КРИТЕРИИ ПРИЁМКИ

### Статус: продукт-слой, консолидация SPEC_FINAL §6–8 и v4 Часть III (З-0021).
### Критерии приёмки = гейты go/no-go. Порядок — по дешевизне опровержения: самые опасные ставки убиваются первыми и на минимальном железе.

---

## Горизонты целей

| Горизонт | Цель | Доказательство |
|---|---|---|
| H1 (недели) | Конвергенция стенда под SPEC_FINAL; E1 пройден | один бинарник реально токен-агностичен |
| H2 (месяц-два) | **E2 пройден — тождество смыслов** | рой над общей гетерархией возможен |
| H3 (квартал) | E3–E4 пройдены; система доказана в малом | Алая фильтрует эхо; петля вопроса замкнута |
| H4 (полгода) | v1.0 «Класс»: пилот 10–30 пар | продукт с живыми учениками |
| H5 (пост-v1.0) | E5–E7: эпохи, башня, переселение | «действующий прототип нового мозга» |
| ⭐ Полярная звезда (параллельно, силами флотов) | M0–M6 по `NORTH_STAR.md`: ≤ 10M параметров ≈ рассуждения 200B+ | паритет со счётом эталона ≥ 200B на L1, затем L2 |

Полярная звезда — внешняя мера, а не гейт ядра: её ступени M0–M1 (мерило и
эталоны) не зависят от E-гейтов и строятся на арене. M2 и выше требуют
выращенного разума и решения О-8 (бюджет параметров против ~40 GB ядра).

## Критерии приёмки по гейтам

### E1 — «Два экземпляра, один бинарник» (smoke обобщения)
Сборка: сантана на «Колобке» + тот же бинарник в конфигурации Алаи
с единственным SantanaDriver.
- [ ] Алая строит граф из SantanaToken'ов;
- [ ] нидана-трасса обоих экземпляров проходит CI (12 меток, Ведана<Упадана,
      Джати→Джара-марана ≤ MAX_LIFETIME);
- [ ] в core/ ни одного ветвления по типу экземпляра (ревью диффа — часть гейта).
- Провал ⇒ неверно выбрана гранула токена/зона cmd (В1) — итерация контракта
  SantanaDriver; дальше не идти.

### E2 — Тождество смыслов (ГЛАВНЫЙ ГЕЙТ ПРОГРАММЫ)
Сборка: 10–100 **настоящих независимых** сантан (З-0009: башня из 3 ядер
не годится) на пересекающихся сказочных шардах → одна Алая.
- [ ] precision ≥ 0.9 и recall ≥ 0.8 отождествления на ground truth
      (границы слов известны);
- [ ] измерено послойно (L1 отдельно от L2) — деградация по башне видна сразу;
- [ ] риск binding (О-3, H16) снят или включён план Б (временный токенизатор).
- Провал ⇒ **стоп программы**, итерация канонической формы адреса (SigRef)
  и/или handshake-стандарта. Все последующие гейты заморожены.

### E3 — Слепое переоткрытие и карантин
- [ ] ≥1 семя закоммичено тремя дизъюнктными группами сантан вслепую;
- [ ] инъекция эха (группа, накачанная одним приором) НЕ проходит COMMIT —
      отрицательный контроль обязателен;
- [ ] наблюдения `initiated_by=TEACHER` корректно исключены из подтверждений.

### E4 — Петля вопроса через Алаю
- [ ] сквозная нидана-трасса вопроса: Санскара(сантана) → Виджняна(Алая) →
      … → Джати(Алая) → SEED → рост статистики исходного узла новичка;
- [ ] `is_genuine_question` новичка сохраняется >80% при работающем downlink
      (приоры не убили Почемучку — центральная проверка на догматизацию);
- [ ] >50% вопросов закрыто внутри роя без LLM-оракула.

### v1.0 «Класс» — приёмка продукта
- [ ] E1–E4 пройдены; HumanTeacherDriver + консоль (граф вживую, поток
      вопросов, кнопка migrate) работают;
- [ ] куррикулум anchor-first обеспечен интерфейсом (урок H7);
- [ ] пилот 10–30 пар: неотвеченные вопросы сантан образуют осмысленную
      карту пробелов учеников (оценка учителя-пилота);
- [ ] отчёты описывают поведение системы и статистику ответов;
      психологические интерпретации человека запрещены шаблоном;
- [ ] θ-пороги Куратора и веса аффекта откалиброваны на пилоте (О-2).

### E5–E7 (пост-v1.0, критерии зафиксированы заранее)
- E5: миграция алфавита штатными SEED; провал → санкционированный откат
  bridge в Тело (не блокирует программу).
- E6: башня 10³; закон F=W/(1−β) держится; фон поглощает ≥98% драйверов;
  неdeградация такта Алаи 10→1000; мета-вопросы агрегаторов проходят
  genuine-тест.
- E7: переселение — новая инстанция воспроизводит различения И зоны
  вопросов прежней; выходит на фронтир ≥5× быстрее дичка при сохранении
  genuine-доли.

## Анти-цели (за что не платим ни часа)

- Скорость (10⁶ тактов/сек) до заморозки семантики — З-0016.
- Новые архитектурные документы до E1 — З-0010.
- Масштаб ради масштаба: башня и 10⁶ агентов — только после E2 и v1.0.
- Повторное вскрытие вопросов В0–В18 консилиума — регресс по определению (З-0007).
