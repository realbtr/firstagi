# SPEC_FINAL v1.0 — FirstAGI / Почемучка / Класс
### Единственный действующий документ. Всё остальное — архив или манифест.

## 0. Тезис проекта

Человеческая жизнь не требует сотен триллионов параметров. Она требует
порядка 10⁷ подтверждённых различений с явной статистикой, явными адресами
дефицитов и явной историей подтверждений. Такая модель не тренируется —
она выращивается: актами внимания, вопрошания и подтверждения. Ядро-10М
(~40 GB) помещается в RAM одного сервера. Мы строим один когнитивный
двигатель, который в разных конфигурациях периферии является учеником
(сантана), учителем групп (агрегатор) и хранилищем человечества (Алая).

## 1. Онтология (неизменяемые инварианты)

1. Один бинарник ядра. Различие агентов = конфигурация драйверов.
   PR с ветвлением «если я Алая» отклоняется без обсуждения.
2. Нет функции вознаграждения. Двигатель — снятие структурной
   неопределённости (LP за сжимаемую новизну; continuation с капом; stress).
3. Гетерархия, не дерево. Внимание — коллапс в точке максимального
   противоречия. Бюджет активных конкурентов W = 7±2 у всех, всегда.
4. Ядро токен-агностично. Вся семантика — в драйверах.
5. Алгоритм разрешения неопределённости — три исхода:
   совпало → CONFIRMED (следующий признак);
   не совпало → REFUTED (новое обобщение, отбраковка);
   контекст пуст → EXPLORING (короткие малообобщённые цепочки).
6. Тело (транспорт+крипто, геном, wall-clock, исполнение spawn/kill,
   энергия) не имеет права на семантику.
7. Нидана-конформность: каждое событие ядра несёт одну из 12 меток;
   ассерты порядка (Ведана<Упадана; Джати→Джара-марана ≤ MAX_LIFETIME) — в CI.

## 2. Субстрат (решение З-0012, З-0014)

ХРАНЕНИЕ: слотмап, Generation Handles, плоские массивы (DOD), связные
списки рёбер. Handle = (slot: u32, generation: u32).

АДРЕСАЦИЯ И ТОЖДЕСТВО: бинарные HDC-векторы D=1024 бит.
- Геном = fixed seed → канонические векторы базиса L0 (аксиома рождения).
- Структура: bind(a,b) = a XOR b; bundle = мажоритарная сумма.
- Близость: расстояние Хэмминга. Уровни разрешения: COARSE/MEDIUM/FINE/EXACT
  = сравнение по префиксу 256/512/768/1024 бит; выбор уровня модулируется
  энергией (Тело) и ставками бифуркации.
- Криптохеши семантики не касаются (урок З-0008); только dedup в Теле.

## 3. Ядро — элементарный цикл (сжатие v2; v2 = архив-справочник)

MeaningToken {id: Handle; driver: DriverTag; level: u8;
  f_cur, f_tgt: HDC1024; cmd: Policy /*посл-ть токенов уровня k−1*/;
  in_stats, out_stats: Map<Handle, BetaCounter>;
  competitors: BoundedSet<Handle, 9>;
  resource_state: RS6; salience: f32; karma_density: f32}

RS6 = {LARGE_GROWING, LARGE_SHRINKING, SUFFICIENT_GROWING,
  SUFFICIENT_STABLE, SCARCE_GROWING, SCARCE_SHRINKING}  // ведана узла

Брокер: зонд = argmin ожидаемой апостериорной энтропии по конкурентам (EIG).
Приоритет сигнала Педагога; лог initiated_by ∈ {SELF, TEACHER} обязателен.
Куратор: phase(6) + полоса устойчивость↔новизна (θ-пороги — О-2).
Консолидация: PENDING → COMMIT/ROLLBACK на границе сна; только COMMIT
покидает агента (uplink) и попадает в отчёты.
Почемучка: EmptyNodeDetector (RS ∈ SCARCE_*) + generate_question через
Брокер; is_genuine_question требует initiated_by==SELF; Teacher Queue
адресует УЗЕЛ, не текущий фокус (async-разрыв закрыт по построению).
Гравитационный фон: SUFFICIENT_STABLE ∧ competitors=∅ → вне W-бюджета,
чтение по дрейфу. Ядро-10М := фон Алаи ∩ порог karma_density.

## 4. Драйверы

CharDriver: символы куррикулума → токены L0 (по геному).
SantanaDriver (контракт): эмиссия по одному токену на закоммиченное
обобщение {f_cur=якорь, f_tgt=различение, cmd=программа внимания};
FIFO внутри драйвера, коммутативность между драйверами (инвариант);
идемпотентность по (tag,seq) — в Теле; команды PROBE/FEED/SEED/RETIRE
доставляются только через канал Педагога (сантана слепа к рою).
HumanTeacherDriver (продукт «Класс»): человек в слоте Педагога; консоль
вопросов; неотвеченное → LLM-оракул + пометка «дыра ученика».
NurseryDriver (пост-v1.0): популяция как периферия Алаи.

## 5. Константы

W=7±2 (все экземпляры) · D=1024 · β≥0.98 → F=W/(1−β)≈350–2300 ·
k_min=3 независимых тега для COMMIT Алаи · такт Алаи = 1 uplink-токен ·
энергия [0,1] режимы REST/CONSERVE/NORMAL/EXPLORE/ABUNDANT →
разрешение COARSE→EXACT · класс v1.0 = 10–30 пар (внутри F одной Алаи).

## 6. Лестница экспериментов (гейты go/no-go)

E1 два экземпляра, один бинарник; нидана-CI зелёный; нет ветвлений по типу.
E2 ГЛАВНЫЙ: 10–100 сантан, тождество смыслов (строитель/верификатор/арбитр
   на HDC-ключах); precision/recall ≥ 0.9/0.8 послойно. Провал → стоп, итерация ключа.
E3 слепые переоткрытия + карантин (отрицательный контроль эха обязателен).
E4 петля вопроса: сантана→Алая(бифуркация)→PROBE→SEED; genuine>80% при
   работающем downlink; >50% вопросов закрыто без LLM.
E5 эпоха, bridge-как-токены (арбитр О-4). E6 башня 10³, β и латентность
   промоции; неdeградация такта Алаи 10→1000 (метрика Qwen).
E7 переселение: RETIRE→дистилляция→SPAWN; наследуются различения И зоны
   вопросов; фронтир в ≥5× быстрее дичка при сохранении genuine-доли.

## 7. Продукт v1.0 «Класс» (= Реинкарнационная песочница)

Состав: E1–E4 + HumanTeacherDriver + консоль (граф вживую, поток вопросов,
кнопка migrate) + отчёты. Петля: ученик учит персональную сантану →
её genuine-вопросы вскрывают его пробелы → неотвеченное = его куррикулум →
Алая класса = карта фронтира группы → прокачка = L(k) пары + учительская
статистика по зонам. Отчёты описывают поведение системы и статистику
ответов; психологические интерпретации человека запрещены шаблоном.
Вне v1.0: башня, эпохи, Nursery, открытая сеть, мультимодальность.

## 8. Итерация 1 (текущая) — definition of done

И1-Т1 репозиторий+скелет+журнал — СДЕЛАНО.
И1-Т2 ядро Фазы 1–2: FractalGraph, MeaningToken, RS6, бюджет 7±2;
      система строит токены L0 на «Колобке».
И1-Т3 геном L0 (seed, алфавит, нормализация, батарея «прописи») + корпус A.
И1-Т4 нидана-enum + ассерты в CI с первого дня.
Done = «Колобок» прочитан, токены растут, RS6 сходится к SUFFICIENT_STABLE
на рефренах, CI зелёный. Оценка: 2 недели.
